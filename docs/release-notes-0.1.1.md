# Nudge 0.1.1

- Keep the real indicator visible throughout customization, with a touch-area guide that lets touches through.
- Make slider changes immediate and keep the chosen center while resizing or dragging.
- Set indicator length as a percentage of the touch area, with independent appearance controls.
- Keep bottom placement at the bottom after rotation; optionally use a separate landscape placement.
- Add **Available on lock screen**, off by default, for the awake lock screen.
- Improve accessibility connection reporting, cleanup and local diagnostics for service disconnections.
- Use the same Nudge icon inside the app and on the launcher.

Install this APK over 0.1.0 without uninstalling to preserve settings. Existing position percentages now represent the trigger's center; indicator length is migrated to its previous proportion. Recheck Accessibility after updating.

Redmi Note 12 / HyperOS-specific behavior, Recents recovery, battery measurements and the installation update check remain pending device testing. Force-stop still requires manual recovery.
