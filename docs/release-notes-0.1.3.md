# Nudge 0.1.3

## Added

- make indicator thickness a percentage (634e444)

Thickness now ranges from 0% to 100% of touch depth and scales when you resize the touch area. New installs default to 25%. Existing dp settings are converted once to preserve their previous proportion, with other customization settings retained.

Install this APK over 0.1.2 without uninstalling to preserve settings. Physical Redmi verification remains pending; see docs/compatibility.md.
